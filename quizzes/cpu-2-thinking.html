Tình huống 1: Phân tích hiệu suất CPU
Bạn là kỹ sư phần cứng và cần đánh giá hiệu suất của một CPU mới. CPU này có:
  • Tốc độ xung nhịp: 3.2 GHz
  • 4 cores, mỗi core có 8 registers
  • ALU có thể thực hiện 2 phép tính đồng thời
  • Cache L1: 32KB, L2: 256KB, L3: 8MB

Tình huống 2: Tối ưu hóa chu kỳ lệnh
Trong một ứng dụng xử lý hình ảnh, bạn nhận thấy CPU thường xuyên phải chờ dữ liệu từ RAM. Chu kỳ lệnh hiện tại:
FETCH → DECODE → EXECUTE → WAIT
Thời gian: Fetch (1ns) → Decode (1ns) → Execute (2ns) → Wait for data (50ns)

Tình huống 3: Thiết kế hệ thống Bus
Bạn đang thiết kế một CPU cho hệ thống nhúng cần xử lý:
  • Bộ nhớ RAM 16GB (cần 34 bit địa chỉ)
  • Dữ liệu 64-bit
  • 16 tín hiệu điều khiển khác nhau
  • Kết nối với 8 thiết bị I/O

Tình huống 4: Phân tích bottleneck
Một hệ thống máy tính đang gặp hiện tượng chậm trong các tác vụ sau:
  • Mở file lớn: rất chậm (30 giây)
  • Tính toán phức tạp: bình thường (2 giây)
  • Chạy nhiều ứng dụng: chậm dần
  • Xử lý đồ họa: rất chậm
