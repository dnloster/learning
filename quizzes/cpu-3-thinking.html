🧠 Tư duy - CPU nâng cao

Mục tiêu: Phân tích và đánh giá hiệu suất CPU trong các tình huống thực tế
Kỹ năng: Tư duy phản biện, phân tích hiệu suất, so sánh kiến trúc

🎯 Tình huống 1: So sánh hiệu suất CPU

Bối cảnh: Bạn là kỹ sư phần cứng cần lựa chọn CPU cho hai ứng dụng khác nhau:

  • Ứng dụng A: Xử lý video 4K realtime (cần nhiều lõi, tính toán song song)
  • Ứng dụng B: Game đơn luồng (cần tần số cao, hiệu suất lõi đơn)

Câu hỏi: Phân tích và đưa ra lựa chọn CPU phù hợp cho từng ứng dụng. Giải thích lý do.

🔧 Tình huống 2: Tối ưu hiệu suất pipeline

Vấn đề: CPU có pipeline 5 giai đoạn đang gặp vấn đề hiệu suất do branch misprediction.

  • Branch prediction accuracy: 85%
  • Pipeline penalty khi misprediction: 10 cycles
  • Tần suất lệnh branch: 20% tổng số lệnh
  • Thông lượng lý tưởng: 1 lệnh/cycle

Câu hỏi: Tính toán hiệu suất thực tế và đề xuất giải pháp cải thiện.

⚡ Tình huống 3: Cache hierarchy optimization

Thách thức: Thiết kế cache hierarchy cho CPU mới với các ràng buộc:

  • Tổng diện tích silicon: 100mm²
  • L1 cache: 0.1mm²/KB, access time: 1 cycle
  • L2 cache: 0.05mm²/KB, access time: 8 cycles
  • L3 cache: 0.02mm²/KB, access time: 25 cycles
  • RAM access: 200 cycles

Câu hỏi: Thiết kế cache hierarchy tối ưu và giải thích quyết định.
