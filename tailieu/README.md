# Thư mục Tài liệu

Thư mục này chứa các file PDF tài liệu tham khảo về:

## Sách và Tài liệu

-   `computer-organization-design.pdf` - Computer Organization and Design (Patterson & Hennessy)
-   `modern-computer-architecture.pdf` - Modern Computer Architecture (Jim Ledin)
-   `digital-design-computer-architecture.pdf` - Digital Design and Computer Architecture (Harris & Harris)
-   `computer-systems-programmer-perspective.pdf` - Computer Systems: A Programmer's Perspective

## Hướng dẫn sử dụng

1. Đặt các file PDF vào thư mục này
2. Đảm bảo tên file khớp với tên trong code
3. File PDF sẽ được hiển thị trong iframe khi click vào nút "Xem PDF"

## Lưu ý

-   Các file PDF nên có kích thước phù hợp để load nhanh
-   Đảm bảo file PDF không có mật khẩu bảo vệ
-   Hỗ trợ các file PDF từ các nguồn khác nhau
